# Identidad de Marca - Guayabera ERP

## Nombre del Proyecto

**Guayabera ERP Suite**

Nombre alternativo: **GuayaBusiness**

### Razonamiento del Nombre:
- "Guayabera" representa la conexión cultural con la región latinoamericana y la identidad local
- "ERP Suite" indica que es un sistema integral de planificación de recursos empresariales
- El nombre evoca tradición, pero con un enfoque moderno y profesional
- Fácil de recordar y pronunciar en español e inglés
- Escalable para futuras versiones y módulos especializados

## Paleta de Colores

### Colores Primarios:
- **Azul Profundo (#1B365D)**: Representa profesionalismo, confianza y estabilidad
- **Verde Empresarial (#2E8B57)**: Simboliza crecimiento, sostenibilidad y éxito financiero
- **Gris Noble (#F5F7FA)**: Para fondos y elementos secundarios, transmite elegancia

### Colores Secundarios:
- **Naranja Destaque (#FF8C42)**: Para llamadas a la acción y elementos importantes
- **Verde Energía (#4A9B3F)**: Indicadores positivos y validaciones
- **Rojo Alerta (#DC3545)**: Errores, alertas y elementos críticos
- **Amarillo Destaque (#F4D03F)**: Notificaciones y elementos de atención media

### Colores Neutros:
- **Negro (#212529)**: Texto principal
- **Gris Oscuro (#6C757D)**: Texto secundario
- **Blanco (#FFFFFF)**: Fondos limpios y espacios importantes

## Tipografía

### Tipografías Recomendadas:
- **Encabezados**: Montserrat o Roboto Bold
- **Texto principal**: Open Sans o Lato
- **Código**: Fira Code o Source Code Pro

## Elementos Visuales

### Logo Conceptual:
- Combinación de una guayabera (camisa típica) con íconos de tecnología
- Forma geométrica limpia y moderna
- Puede simplificarse a un ícono para dispositivos móviles
- Debe transmitir estabilidad y modernidad

### Iconografía:
- Íconos lineales y minimalistas
- Consistentes con la paleta de colores
- Adaptados para accesibilidad (alto contraste)

## Principios de Diseño

### Profesional:
- Interfaces limpias y organizadas
- Jerarquía visual clara
- Elementos bien alineados

### Moderno:
- Diseño plano con toques de profundidad
- Espacios blancos equilibrados
- Transiciones suaves

### Adaptativo:
- Responsive design por defecto
- Modo oscuro y claro
- Compatible con múltiples dispositivos

### Escalable:
- Sistema de componentes modulares
- Diseño atómico para fácil expansión
- Arquitectura flexible para nuevas tecnologías

## Aplicación en Interfaz de Usuario

### Header y Navegación:
- Fondo azul profundo (#1B365D)
- Texto blanco
- Íconos verdes empresariales (#2E8B57) para elementos interactivos

### Contenido Principal:
- Fondo gris noble (#F5F7FA)
- Tarjetas blancas con sombras sutiles
- Botones naranja destaque (#FF8C42) para acciones principales

### Estados:
- Botones primarios: Verde empresarial (#2E8B57)
- Botones secundarios: Azul profundo (#1B365D)
- Botones de peligro: Rojo alerta (#DC3545)
- Botones de advertencia: Amarillo destaque (#F4D03F)

## Consideraciones de Accesibilidad

- Contraste suficiente entre texto y fondo (ratio 4.5:1 mínimo)
- Soporte para lectores de pantalla
- Atajos de teclado
- Modo alto contraste disponible

## Aplicación Cross-Platform

- Coherencia visual entre web, móvil y escritorio
- Componentes adaptables
- Iconografía consistente
- Tipografía legible en todos los dispositivos
