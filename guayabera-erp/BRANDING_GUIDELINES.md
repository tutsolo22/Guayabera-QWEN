# Guía de Identidad de Marca - GuayaERP

## Nombre del Producto

**Nombre Oficial:** GuayaERP
**Nombre Comercial:** GuayaERP
**Abreviatura:** GE

### Origen del Nombre

El nombre "GuayaERP" deriva de "Guayabera", una prenda tradicional mexicana que simboliza la fusión entre tradición y modernidad. Al igual que la camisa guayabera, que combina funcionalidad y estilo, GuayaERP une tecnología moderna con procesos empresariales probados.

## Directrices de Uso

### Correcto Uso de Colores
- Azul Profundo para elementos principales
- Verde Corporativo para acciones
- Gris Neutro para fondos
- Verde Acuático para elementos innovadores
- Amarillo Energético para alertas

### Incorrecto Uso
- No mezclar excesivamente colores secundarios
- No usar colores primarios en áreas secundarias
- No crear combinaciones que disminuyan la legibilidad

### Espaciado y Dimensiones
- Mantener espacios consistentes entre elementos
- Usar unidades relativas para escalabilidad
- Respetar la jerarquía visual

## Beneficios de la Identidad

Esta identidad visual proporciona:

1. **Profesionalismo:** Colores corporativos que transmiten confianza
2. **Adaptabilidad:** Paleta y diseño que permiten evolución tecnológica
3. **Memorabilidad:** Nombre corto y colores distintivos
4. **Internacionalidad:** Nombre y colores neutrales culturalmente
5. **Escalabilidad:** Diseño modular para expansión de funcionalidades
6. **Consistencia:** Directrices claras para desarrollo futuro
